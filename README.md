# Multiai_bot

様々なAIモデルをDiscord上で簡単に利用できる高機能なBotです！

## 🌟 特徴
- 複数のAIモデル（Gemini, DeepSeek, Xiaomi MiMo）を切り替えて会話可能
- チャンネルごとに異なるAIを設定可能
- 画像生成や画像認識にも対応（Gemini）
- AIの「性格（プロンプト）」をユーザーごとに自由にカスタマイズ可能
- 各種便利コマンド（天気、仮想通貨、ニュース、楽天商品検索）を搭載

## 🚀 使い方

### 1. メインの会話機能
Botは設定されたチャンネルでのメッセージに自動で返信します。
メンション（`@Bot`）や特定のリプライを飛ばす必要はありません。

### 2. チャンネルごとのAI設定
サーバーの管理者のみが実行可能なコマンドです。
- `/setchannel [AIの種類]` 
  - 選択できるAI: `Gemini`, `DeepSeek`, `Xiaomi MiMo`
  - 実行したチャンネルが、選んだAIとの専用会話チャンネルになります。

### 3. AIの性格カスタマイズ
- `/setpersonality`
  - あなた専用のAIの「性格」や「口調」を自由に設定できます（例：「関西弁で話して」「ツンデレな妹として振る舞って」など）。設定はあなた個人に保存されます。

### 4. その他の便利コマンド（スラッシュコマンド）
チャット欄で `/` を入力して使用できる機能です。
- `/memory_clear` : AIの記憶（直近の会話履歴）をリセットします。話題を変えたい時に便利です。
- `/weather [地域]` : 指定した地域の天気予報をAIが教えてくれます。
- `/coin` : 現在の仮想通貨（ビットコインなど）の価格とトレンドを表示します。
- `/news` : 最新の主要ニュースをいくつかピックアップして要約します。
- `/rakuten` : 楽天市場の指定した商品を検索し、価格とリンクを表示します。

## ⚠️ 注意事項
- 文字数上限（2000文字）を超える返答は、AIが自動で要約・省略して返信します。
- AIの性格設定に過激な言葉（暴力、自傷、アダルトなど）が含まれている場合、各AIの安全フィルターに弾かれてエラーになることがあります。エラーが続く場合は `/memory_clear` を行うか、`/setpersonality` で無害な設定に戻してください。
